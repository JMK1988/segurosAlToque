# API Seguros al Toque

Backend Node.js/TypeScript para multicotizar autos en Provincia y San Cristobal.

## Scripts

- `npm run dev`: levanta en modo desarrollo
- `npm run build`: compila TypeScript a `dist`
- `npm start`: ejecuta la build
- `npm test`: corre pruebas con Jest

## Endpoint principal

- `POST /api/v1/quotes/auto/multi`

Consultar contrato en `openapi.yaml`.
