* Dirígete al siguiente enlace:  [https://apiportal.mercantilandina.com.ar/](https://apiportal.mercantilandina.com.ar/)

 **Paso 2: Registro en el Portal**

* En el portal, podrás registrarte utilizando tus datos personales. Seguí las indicaciones para completar el proceso de registro.

** Paso 3: Suscripción a los Productos API**

* Una vez registrado e iniciada la sesión, explora los "Productos" disponibles.  
* Selecciona y suscríbite a los Productos API que necesite para su integración.

** Paso 4: Obtención de la "Subscription Key"**

* Después de suscribirte a los Productos, dirígete a la sección "Perfil" dentro del portal.  
* Allí, podrás visualizar los Productos a los que se te has suscripto y encontrarás sus correspondientes "subscription keys". Estas claves serán necesarias para la autenticación.

** Paso 5: Generación del Token de Acceso (Credenciales de MA)**

* Para generar el token de acceso, se requerirá un usuario y una contraseña específicos.  
* Estas credenciales te serán proporcionadas directamente por Mercantil Andina (MA) una vez que hayas completado la suscripción a los Productos API deseados. Estate atento a la comunicación de MA con esta información.

**Paso 6: Creación del Usuario de Test (Vinculación de Cuentas)**
